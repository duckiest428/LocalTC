# LocalTC Teaser Video Script and Storyboard

## Working title

**Talk to ATC. Fly the flight.**

## Recommended runtime

**2 minutes 10 seconds** for the main teaser.

Also capture the material for:

- 30-second social cut
- 60-second website cut
- silent captioned version

## Core promise

LocalTC is free ATC for Microsoft Flight Simulator 2024 that you can talk to. It runs on the pilot's PC, works offline after setup, answers from clearance delivery through the gate, and includes an optional first officer on the intercom.

Do not imply that LocalTC is a replacement for VATSIM, real-world ATC, GSX, cabin crew, multiplayer ATC, or features marked as planned. Do not show roadmap features as if they are already available.

## Tone and visual language

- Start intimate and quiet: cockpit, headset, hands near the controls.
- Build toward a busy, alive radio frequency.
- Let the actual radio dialogue carry the story.
- Use LocalTC's UI as evidence, not as a wall of feature cards.
- Use restrained captions: one idea at a time, large enough to read on a phone.
- Keep the aircraft and the radio as the visual focus.
- Use the app's real radio static, station voices, map, and copilot audio.
- Avoid generic stock aviation footage unless it is only a brief transition.

## Required capture setup

### Flight

Capture a short IFR flight in MSFS 2024 with:

- a recognizable airliner or aircraft the creator actually flies
- a gate departure
- clearance delivery
- pushback or taxi
- tower handoff
- departure or center handoff
- descent and approach
- landing and taxi to the gate

A route of 25-45 minutes is enough for the video. Record a longer flight if needed, then use the strongest moments.

### LocalTC

Enable:

- Developer mode and recording
- ATC voice
- radio effects and moderate static
- the live map
- the radio log
- copilot intercom if the aircraft profile is known to work
- a local voice provider that is reliable on the capture PC

Use cloud LLM or cloud TTS only if the creator has already tested the connection. The main message must remain true with local/offline operation.

### Capture angles

Record clean source footage separately:

1. MSFS cockpit view
2. external aircraft view during taxi or climb
3. LocalTC radio log
4. LocalTC live map
5. copilot/intercom UI
6. PTT hand or yoke button
7. final gate arrival

Record each radio exchange as a clean take. Do not rely on one long live recording for every edit.

# Main 2:10 Storyboard

## 00:00-00:06 - Cold open: the question

### Visual

Black screen for half a second. Cut immediately to a cockpit view at the gate. Headset on the desk or pilot's hand near the push-to-talk key. Engines quiet.

Show a small LocalTC radio log edge or a clean cockpit view, but do not explain the product yet.

### Audio

Cockpit room tone. A faint radio hiss fades in.

### Voice / radio

Pilot, natural and slightly uncertain:

> "Cleveland Clearance, Frontier 3916, IFR to Orlando, ready to copy."

Cut before the answer finishes.

### On-screen text

None. Let the question create curiosity.

# Capture and editing checklist

## Before recording

- Use a clean Windows/MSFS installation with the current LocalTC release.
- Confirm the selected aircraft profile and copilot controls work before recording.
- Start Developer Mode recording.
- Hide unrelated desktop notifications.
- Set the LocalTC window to a readable size.
- Test microphone levels and radio static.
- Capture clean room tone and one minute of radio noise.
- Prepare the exact flight plan and runway shown in the script.

## During recording

- Record the cockpit and UI separately when possible.
- Keep all radio calls short and natural.
- Leave 1-2 seconds of silence before and after each call for editing.
- Capture the pilot's hands pressing PTT at least twice.
- Mark every successful clearance, handoff, copilot callout, question, correction, approach, and gate arrival.
- Do not fake a copilot cockpit action. Show it only if the current aircraft profile has been verified.

## Audio mix

- Pilot radio: centered, clear, lightly filtered.
- ATC: radio band-limit, static, and squelch, but keep words intelligible.
- Copilot: dry intercom, close, slightly warmer, no radio static.
- UI clicks: quiet and short.
- Music: optional, low under the radio, absent during important transmissions.
- Never let music or UI sound cover a callsign, clearance, runway, or frequency.

## Text and claims to avoid

Do not claim:

- multiplayer ATC
- VATSIM integration
- GSX or ground crew integration
- cabin crew
- worldwide real-world ATC coverage
- perfect aircraft control
- real-world aviation use
- that every aircraft supports every copilot control

Use the actual shipped claims:

- free forever
- local by default
- works offline after setup
- talk naturally to ATC
- clearance, ground, tower, departure, center, and approach
- readbacks and handoffs
- optional copilot
- live map, radio log, replay, and logbook
